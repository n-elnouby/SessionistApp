Frequently asked

Where is my data stored?

On your devices and in your own iCloud account. Sessionist has no account and the developer can't see your library. Deleting the app on every device and removing its iCloud data deletes it.

My iPhone and Mac show different games.

First check the filters and sorting in each tab — they're set per device. Then open Settings → Sync Status on both: it shows when each device last synced. If one is really out of step, use Repair Sync there; it re-downloads the library from iCloud and adds back anything only that device had.

How does tracking work on the iPhone?

Start a session in the app, from a widget, the Live Activity or Shortcuts. To start and stop automatically when you open a game, set up the Shortcuts automation from Settings.

How does tracking work on the Mac?

Add your games under Scan, and Sessionist starts a session when a game opens and stops it when it quits. Sessionist has to be running (it lives in the menu bar); turn on Open at Login in Settings.

GeForce NOW isn't tracked.

Add the game from its GeForce NOW desktop shortcut, then allow Sessionist to read the GeForce NOW log folder when it asks. Time in the queue isn't counted; the session starts when the stream does.

Steam Sync finds no games.

Steam only shares games and playtime for public profiles. In Steam, set Profile and Game details to Public, then sync again.

What is Community Lengths?

If you turn it on in Settings, the playtime of games you finish is shared anonymously, and every game shows how long Sessionist players took once at least three have shared it. Turn it off any time and choose to remove what you shared. See Privacy.
